# Casos de aceptación

- CA-01: operador crea agricultor y parcela.
- CA-02: cruce horario de turnos es rechazado.
- CA-03: pago digital pendiente no reduce deuda; confirmación sí.
- CA-04: devolución ejecutada restituye saldo.
- CA-05: fecha cerrada rechaza movimientos.
- CA-06: solo administrador reabre con motivo.
- CA-07: los tres roles respetan la matriz.
- CA-08: segunda ejecución demo no duplica datos.
- CA-09: reportes PDF/Excel se descargan.
- CA-10: Auditoría registra operaciones mutables.
