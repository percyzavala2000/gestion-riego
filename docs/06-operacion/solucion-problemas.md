# Solución de problemas

- `release version 21 not supported`: cambia Maven a Java 21.
- `no configuration file provided`: ejecuta Docker Compose desde la raíz.
- Flyway checksum: no edites migraciones aplicadas.
- Puerto ocupado: identifica el proceso o cambia el puerto.
- Acceso 403: revisa rol y ruta.
- Error financiero: busca `X-Correlation-Id` en Auditoría y logs.
- Seed duplicado: el usuario `demo_admin` hace que la segunda carga se omita.
