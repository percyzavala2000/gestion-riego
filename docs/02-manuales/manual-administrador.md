# Manual del administrador

1. Ingresa con una cuenta administradora.
2. Revisa el Dashboard y las alertas operativas/financieras.
3. En Usuarios, crea cuentas, asigna roles y cambia contraseñas. No desactives tu propia cuenta ni el último administrador.
4. Gestiona agricultores, parcelas y turnos conservando el historial.
5. Supervisa Tesorería, cuentas, caja y reportes.
6. Reabre un cierre solo con motivo documentado.
7. Consulta Auditoría por usuario, ruta o correlación.
8. Verifica respaldos y ejecuta pruebas de restauración.

Nunca compartas credenciales, edites migraciones aplicadas ni uses datos demo como información oficial.
